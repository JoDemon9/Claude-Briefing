The clarification supersedes blanket mandatory-photo and minimum-story-count blockers for new editions from 22 October only. availability_policy=partial-v1 preserves useful supported reporting when a quote, photograph, sports source, forecast or extra story is unavailable. Only the affected item is unavailable/archival or omitted. Overdue opportunities keep original verified_at, carry review_due and lose active application promotion. No placeholder or guessed claim fills a gap. Genuine unsafe paths, inconsistent identities/times, invalid structural data, absence of any supported article, failed integrity/preview or failed publication still block release. Research targets and the historical cutoff remain; filler and fake exception evidence do not.

The publisher uses existing checked artifacts, normal worktrees and allowlists. It checks actual source Pages before central sync and actual Oracle Pages afterward, with bounded CDN retry. Missing publication credentials and Git races are explicit failures, not reported as success. The broken workflow secret conditional/portal CLI and the fake live-verification shortcut are removed. RSS metadata remains discovery; filtering excludes betting/youth noise. No scheduler or external model API is added.

Preserve historical source/quote/publication times, URLs, independent readers, daily composition, Wire commits, private/public boundaries and existing task schedules/settings/model. Prompts are files; actual Scheduled Task installation requires a separate operation and is not implied by commits.

Validation evidence and exact completion status belong in the audit report and PR. No claim that main, production Pages, portal credentials or live Scheduled Tasks have been changed is made by this decision record. Older DEC-008/017/021/022 statements are superseded only where this record and the user's clarification explicitly differ.
