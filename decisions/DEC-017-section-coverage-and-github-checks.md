Later editions may retain useful earlier reporting as clearly dated context with original article/source times and stable identity, adding meaningful developments and missed major stories. This does not create new reporting or justify re-dating unchanged content. No filler, forced research of every tracked item, invented sources/photos or inferred outcomes is permitted.

The existing GitHub PR workflow now prepares selected licensed images, then validates/builds/tests source candidates and returns the exact public docs artifact plus a compact report with checked/source commit, workflow run, release/profile and section counts. Main still requires generated files committed. Publisher receipt consumption verifies the complete release manifest and required profile and skips a redundant build for an identical tested artifact. Changed files or insufficient proof block reuse. Detailed logs are read only for failures. CI does not perform editorial judgement or prove claims.
