## Luna workflow and preserved quality

The user's choice of Luna explicitly supersedes older same/no-new-model wording only for ChatGPT model selection. No paid AI/API, model-specific client or new scheduler is added. The task API exposed to this maintenance session cannot set a model; prompts do not change the actual model. LUNA_WORKFLOW.md documents that limitation and the selection/verification step.

prepare_run.py composes existing research, collection and sports helpers into one private handoff: full evidence reports, current producer contract, all bounded planning pages, source-failure inventory and explicit editorial steps. It does not write articles/editions, grant reading/review, change verified_at or publish. Private storage must be outside the public checkout, including resolved symlinks. sports_news.py --apply-report applies the already prepared report to its matching draft without fetching twice.

All three maintained prompts specify preparation, actual evidence reading, one draft, one editorial review and GitHub mechanics. Concise private claim/source notes support new/changed facts. The review checks support/numbers/chronology/independence/omissions/Greek; useful analysis adds a supported comparison, mechanism or consequence. Five International/five Cyprus targets, researched shortages, broad discovery, all markets/tech/rates, per-slot weather, opportunities, licensed images, original times/identities and all publication gates remain. No quality improvement or quota saving is claimed without measured runs.
